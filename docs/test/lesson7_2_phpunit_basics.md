### 📝 ステップ2：Controller にメソッドを追加

**🐘ガネーシャ：** 「作成されたファイルを開いて、以下の内容に**置き換え**てな」

```php
<?php
// app/Http/Controllers/Api/TestController.php

namespace App\Http\Controllers\Api;

use Illuminate\Http\JsonResponse;

class TestController extends ApiController
{
    /**
     * テスト用：シンプルなレスポンスを返す
     */
    public function ping(): JsonResponse
    {
        return response()->json([
            'message' => 'pong',
            'status' => 'ok',
        ]);
    }

    /**
     * テスト用：受け取ったデータをそのまま返す
     */
    public function echo(): JsonResponse
    {
        return response()->json([
            'received' => request()->all(),
        ]);
    }
}
```

**👩‍💻ユーザー：** 「保存しました！」

**🐘ガネーシャ：** 「ええな。この API は超シンプルや」

│                                                             │
│  ping()  → 固定のレスポンスを返す                          │
│           { "message": "pong", "status": "ok" }             │
│                                                             │
│  echo()  → 送ったデータをそのまま返す                      │
│           { "received": { 送ったデータ } }                  │

## 📖 第5章：テストの基本パターン（AAA パターン）

### 🎭 テストには決まった書き方がある

**🐘ガネーシャ：** 「さっき書いたテスト、実はある**パターン**に沿っとるんや」

**👩‍💻ユーザー：** 「パターン？」

**🐘ガネーシャ：** 「**AAA パターン**っていうんや。覚えときや」

```
┌─────────────────────────────────────────────────────────────┐
│                   AAA パターン                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1️⃣  Arrange（準備）                                        │
│      → テストに必要なデータを用意する                       │
│                                                             │
│  2️⃣  Act（実行）                                            │
│      → テスト対象の処理を実行する                           │
│                                                             │
│  3️⃣  Assert（検証）                                         │
│      → 結果が期待通りか確認する                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

### 📝 さっきのテストを AAA で見てみる

**🐘ガネーシャ：** 「さっき書いたテストを AAA パターンで見てみよか」

```php
public function test_ping_returns_pong(): void
{
    // ============================================
    // 1. Arrange（準備）
    // ============================================
    // → 今回は認証不要なので、特に準備なし！

    // ============================================
    // 2. Act（実行）
    // ============================================
    $response = $this->getJson('/api/test/ping');

    // ============================================
    // 3. Assert（検証）
    // ============================================
    $response->assertStatus(200);
    $response->assertJson([
        'message' => 'pong',
        'status' => 'ok',
    ]);
}
```

**👩‍💻ユーザー：** 「準備 → 実行 → 検証 の流れですね！」

**🐘ガネーシャ：** 「せや！この流れを覚えておけば、どんなテストも書けるようになるで」

---

### 🍳 料理で例える AAA パターン

**🐘ガネーシャ：** 「料理で例えると分かりやすいで」

```
┌─────────────────────────────────────────────────────────────┐
│                🍳 料理で例える AAA パターン                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【作りたい料理】目玉焼き                                   │
│                                                             │
│  1️⃣  Arrange（準備）                                        │
│      → 卵を用意する                                         │
│      → フライパンを温める                                   │
│      → 油をひく                                             │
│                                                             │
│  2️⃣  Act（実行）                                            │
│      → 卵を割って焼く                                       │
│                                                             │
│  3️⃣  Assert（検証）                                         │
│      → 白身は固まってるか？ ✅                              │
│      → 黄身は半熟か？ ✅                                    │
│      → 焦げてないか？ ✅                                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**👩‍💻ユーザー：** 「なるほど！テストも料理も同じ流れなんですね」

**🐘ガネーシャ：** 「せや！どんなテストもこの3ステップで書けるんや」

// tests/Feature/Api/TestControllerTest.php

namespace Tests\Feature\Api;

use Tests\TestCase;

class TestControllerTest extends TestCase
{
    /**
     * /api/test/ping が正しいレスポンスを返す
     */
    public function test_ping_returns_pong(): void
    {
        // 1. Arrange（準備）
        // → 認証不要なので、特になし

        $response = $this->getJson('/api/test/ping');

        // 3. Assert（検証）

    public function test_echo_returns_received_data(): void

        // ============================================
        // 3. Assert（検証）
        // ============================================
        $response->assertStatus(200);
        $response->assertJson([
            'received' => [
                'name' => 'テスト太郎',
                'age' => 25,
            ],
        ]);
    }
}
```

### 📊 GET と POST の違い

```
┌─────────────────────────────────────────────────────────────┐
│                  GET と POST の違い                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【GET リクエスト】                                         │
│  $this->getJson('/api/test/ping');                          │
│  → データを送らずにリクエスト                              │
│  → Postman で「GET を選んで Send」と同じ                   │
│                                                             │
│  【POST リクエスト】                                        │
│  $this->postJson('/api/test/echo', $sendData);              │
│  → データを送ってリクエスト                                │
│  → Postman で「POST を選んで Body に JSON 入れて Send」と同じ│
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 📖 第7章：PHPUnit と Laravel の関係

### 🎭 PHPUnit って何？

**👩‍💻ユーザー：** 「そういえば、さっきから出てくる PHPUnit って何ですか？」

**🐘ガネーシャ：** 「ええ質問や。**PHPUnit は PHP のテストを書くためのツール**なんや」

```
┌─────────────────────────────────────────────────────────────┐
│                  PHPUnit とは                                │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  🍳 料理で例えると...                                        │
│                                                             │
│    料理を作る        → コードを書く（PHP）                  │
│    キッチン用品      → テストツール（PHPUnit）              │
│    フライパン、包丁  → assertStatus、assertJson など        │
│                                                             │
│  キッチン用品がないと料理しづらいように、                   │
│  PHPUnit がないとテストが書きづらいんや！                   │
│                                                             │
│  ✅ Laravel には最初から PHPUnit が入ってる                 │
│  → インストール不要！すぐ使える！                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**👩‍💻ユーザー：** 「Laravel には最初から入ってるんですね！」

**🐘ガネーシャ：** 「せや。だから `sail artisan test` コマンドですぐテストが実行できるんや」

### 📊 Laravel プロジェクトのテスト構成

**🐘ガネーシャ：** 「Laravel のテストに関係するファイルを見てみよか」

```
┌─────────────────────────────────────────────────────────────┐
│               Laravel テストの構成                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   プロジェクト/                                              │
│   ├── app/           ← 本番コード                           │
│   │   └── Http/Controllers/Api/                             │
│   │       └── TestController.php  ← これをテストする        │
│   │                                                         │
│   ├── tests/         ← テストコードを置く場所               │
│   │   ├── Feature/   ← 機能テスト（API など）               │
│   │   │   └── Api/                                          │
│   │   │       └── TestControllerTest.php  ← テストコード    │

### 📊 Feature テストと Unit テストの違い

**🐘ガネーシャ：** 「テストには2種類あるんや」

```
┌─────────────────────────────────────────────────────────────┐
│                  テストの種類                                │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【Feature Test（機能テスト）】← 今回やってるやつ           │
│    → API 全体が正しく動くかテスト                          │
│    → 「リクエストを送ってレスポンスを確認」                │
│    → Postman でやってたことをコードにしたもの              │
│                                                             │
│  【Unit Test（単体テスト）】                                 │
│    → 1つの関数やメソッドだけをテスト                       │
│    → 「この計算ロジック、正しく動く？」                    │
│    → 部品単位のテスト                                      │
│                                                             │
│  🚗 車で例えると...                                          │
│    Feature Test → 車全体が走れるかテスト                   │
│    Unit Test    → エンジン単体が動くかテスト               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**👩‍💻ユーザー：** 「今回は Feature Test をやってるんですね！」

**🐘ガネーシャ：** 「せや！API のテストは Feature Test で書くのが基本や」

## 📖 第10章：テスト実行コマンドまとめ

### 🎭 よく使うコマンド

**🐘ガネーシャ：** 「最後に、テストを実行するコマンドをまとめとくで」

```bash
# ======================================
# すべてのテストを実行
# ======================================
sail artisan test
sail artisan test

# ======================================
# 特定のテストファイルだけ実行
# ======================================
sail artisan test --filter=TestControllerTest
sail artisan test --filter=TestControllerTest

# ======================================
# 特定のテストメソッドだけ実行
# ======================================
sail artisan test --filter=test_ping_returns_pong
sail artisan test --filter=test_ping_returns_pong

# ======================================
# 失敗したらすぐ止める（CI向け）
# ======================================
sail artisan test --stop-on-failure

# ======================================
# 詳細な出力
# ======================================
sail artisan test --verbose
```

**👩‍💻ユーザー：** 「`--filter` オプションが便利ですね！」

**🐘ガネーシャ：** 「せや。開発中は特定のテストだけ実行することが多いからな」
