## 📖 第1章：エラーコードの意味を理解しよう

### 🏪 コンビニで例えるエラーコード

**🐘ガネーシャ：** 「テストを書く前に、エラーコードの意味を理解しとこか。コンビニで例えると分かりやすいで」

```
┌─────────────────────────────────────────────────────────────┐
│              🏪 コンビニで例えるエラーコード                 │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【401 Unauthorized】「お前誰やねん」                       │
│  👩‍💻「会員限定商品ください」                                │
│  🏪「会員証見せてください」                                  │
│  👩‍💻「持ってないです...」 → ログインしてない！             │
│                                                             │
│  【403 Forbidden】「お前じゃダメや」                        │
│  👩‍💻「プレミアム商品ください」（普通会員証を見せながら）    │
│  🏪「ゴールド会員限定です」 → 権限がない！                  │
│                                                             │
│  【404 Not Found】「そんなもん無いで」                      │
│  👩‍💻「恐竜の卵ください」                                    │
│  🏪「そんな商品ありません」 → 存在しない！                  │
│                                                             │
│  【422 Unprocessable】「入力おかしいで」                    │
│  👩‍💻「会員登録お願いします」（名前欄が空白）                │
│  🏪「名前書いてないですよ」 → バリデーションエラー！        │
│                                                             │
│  【409 Conflict】「ルール的にアカンで」                     │
│  👩‍💻「返品したいです」（3ヶ月前のレシート）                 │
│  🏪「返品期限1週間です」 → ビジネスルール違反！             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**👩‍💻ユーザー：** 「401 は『名乗れ』、403 は『名乗ったけどダメ』ってことですね！」

**🐘ガネーシャ：** 「完璧や！この2つは混同しやすいから、しっかり覚えときや」

### 📝 タイトルが空の場合のテスト

```php
// tests/Feature/Api/TaskApiTest.php に追加

/**
 * タイトルが空の場合は422エラーになる
 */
public function test_タイトルが空の場合は422エラーになる(): void
{
    // ============================================
    // 1. Arrange（準備）
    // ============================================
    // setUp で作成した user, project を使用

    // ============================================
    // 2. Act（実行）
    // ============================================
    $response = $this->actingAs($this->user)
        ->postJson("/api/projects/{$this->project->id}/tasks", [
            'title' => '',  // ← 空っぽ！

    // ============================================
    // 3. Assert（検証）
    // ============================================

    // タスクが作成されていないことも確認
```

### 📝 権限がない場合のテスト

```php
// tests/Feature/Api/ProjectApiTest.php に追加

/**
 * project_member はプロジェクトを削除できない（403）
 */
public function test_memberはプロジェクトを削除できない(): void
{
    // ============================================
    // 1. Arrange（準備）
    // ============================================
    // プロジェクトのオーナー（他人）
    $owner = User::factory()->create([
        'name' => 'オーナー太郎',
    ]);

    // 普通のメンバー（自分）
    $member = User::factory()->create([
        'name' => 'メンバー花子',
    ]);

    // プロジェクトを作成
    $project = Project::factory()->create([
        'name' => 'チームプロジェクト',
    ]);

    // オーナーとしてプロジェクトに参加
    Membership::factory()->create([
        'user_id' => $owner->id,
        'project_id' => $project->id,
        'role' => 'project_owner',  // ← オーナー
    ]);

    // 普通のメンバーとしてプロジェクトに参加
    Membership::factory()->create([
        'user_id' => $member->id,
        'project_id' => $project->id,
        'role' => 'project_member',  // ← 一般メンバー
    ]);

    // ============================================
    // 2. Act（実行）
    // ============================================
    // 一般メンバーがプロジェクトを削除しようとする
    $response = $this->actingAs($member)
        ->deleteJson("/api/projects/{$project->id}");

    // ============================================
    // 3. Assert（検証）
    // ============================================
    $response->assertStatus(403);

    // プロジェクトが削除されていないことも確認
    $this->assertDatabaseHas('projects', [
        'id' => $project->id,
        'name' => 'チームプロジェクト',
    ]);
}
```

**👩‍💻ユーザー：** 「オーナーと一般メンバーの両方を作ってる！これで現実的な状況を再現できるんですね」

**🐘ガネーシャ：** 「その通りや！実際のアプリでも、プロジェクトには必ずオーナーがおるやろ？その状況でメンバーが削除しようとしたら 403 になる、ってことをテストしとるんや」

### 📝 参加していないプロジェクトのタスクへのアクセス（403）

**🐘ガネーシャ：** 「403 にはもう1つ重要なパターンがあるで。**参加してないプロジェクトのタスク**にアクセスしようとする場合や」

**👩‍💻ユーザー：** 「他人のプロジェクトのタスクですね」

**🐘ガネーシャ：** 「せや！ログインはしてるけど、そのプロジェクトのメンバーじゃないから権限がない、ってことや」

```php
// tests/Feature/Api/TaskApiTest.php に追加

/**
 * 参加していないプロジェクトのタスクにはアクセスできない（403）
 */
public function test_参加していないプロジェクトのタスクにはアクセスできない(): void
{
    // ============================================
    // 1. Arrange（準備）
    // ============================================
    // 他人のプロジェクトとタスクを作成
    $otherUser = User::factory()->create();
    $otherProject = Project::factory()->create();
    
    Membership::factory()->create([
        'user_id' => $otherUser->id,
        'project_id' => $otherProject->id,
        'role' => 'project_owner',
    ]);
    
    $otherTask = Task::factory()->create([
        'project_id' => $otherProject->id,
        'created_by' => $otherUser->id,
    ]);

    // ============================================
    // 2. Act（実行）
    // ============================================
    // 参加していないプロジェクトのタスクにアクセス
    $response = $this->actingAs($this->user)
        ->getJson("/api/tasks/{$otherTask->id}");

    // ============================================
    // 3. Assert（検証）
    // ============================================
    $response->assertStatus(403);
}
```

**👩‍💻ユーザー：** 「タスクは存在するけど、自分が参加してないプロジェクトだから 403 になるんですね！」

**🐘ガネーシャ：** 「せや。これは**セキュリティ的にも重要**なテストや。他人のデータを勝手に見れたらアカンからな」


### 📝 doing ステータスのタスクは開始できない

```php
// tests/Feature/Api/TaskApiTest.php に追加

/**
 * doing ステータスのタスクは開始できない（409）
 */
public function test_doingステータスのタスクは開始できない(): void
{
    // ============================================
    // 1. Arrange（準備）
    // ============================================
    // すでに doing 状態のタスクを作成
    $task = Task::factory()->create([
        'project_id' => $this->project->id,
        'created_by' => $this->user->id,
        'status' => 'doing',  // ← すでに作業中！
    ]);

    // ============================================
    // 2. Act（実行）
    // ============================================
    // 開始しようとする（でも、もう doing だから失敗するはず）
    $response = $this->actingAs($this->user)
        ->postJson("/api/tasks/{$task->id}/start");

    // ============================================
    // 3. Assert（検証）
    // ============================================
    $response->assertStatus(409);
    $response->assertJson([
        'message' => '未着手のタスクのみ開始できます',
    ]);

    // ステータスが変わっていないことも確認
    $this->assertDatabaseHas('tasks', [
        'id' => $task->id,
        'status' => 'doing',  // ← doing のまま
    ]);
}
```
