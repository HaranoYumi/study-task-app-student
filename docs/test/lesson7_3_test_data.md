```php
<?php
// まだダメな例

namespace Tests\Feature\Api;

use App\Models\User;
use Tests\TestCase;

class UserTest extends TestCase
{
    public function test_can_get_authenticated_user(): void
    {
        // ============================================
        // 1. Arrange（準備）
        // ============================================
        // ユーザーを直接作成してみる
        $user = new User();
        $user->name = 'テスト太郎';
        $user->email = 'test@example.com';
        $user->password = bcrypt('password');
        $user->save();

        // ============================================
        // 2. Act（実行）
        // ============================================
        // このユーザーとしてログインした状態でリクエスト
        $response = $this->actingAs($user)
            ->getJson('/api/user');

        // ============================================
        // 3. Assert（検証）
        // ============================================
        $response->assertStatus(200);
        $response->assertJson([
            'name' => 'テスト太郎',

}
```

## 📖 第2章：RefreshDatabase を理解しよう

### 🎭 RefreshDatabase って何？

**🐘ガネーシャ：** 「まず RefreshDatabase から説明するで。これは**テストのたびにDBをリセットしてくれる魔法**や」

**👩‍💻ユーザー：** 「魔法...！」

---

### 📝 使い方

**🐘ガネーシャ：** 「使い方は超簡単。テストクラスに1行追加するだけや」

```php
<?php

namespace Tests\Feature\Api;

use Illuminate\Foundation\Testing\RefreshDatabase;  // ← これを追加
use Tests\TestCase;

class UserTest extends TestCase
{
    use RefreshDatabase;  // ← これを追加するだけ！

    public function test_can_get_authenticated_user(): void
    {
        // ...
    }
}
```

**👩‍💻ユーザー：** 「`use RefreshDatabase;` を書くだけ？」

**🐘ガネーシャ：** 「せや！これだけで、**テストメソッドが実行されるたびにDBがリセット**されるんや」

---

### 🔍 RefreshDatabase の仕組み

**🐘ガネーシャ：** 「裏で何が起きてるか説明するで」

```
┌─────────────────────────────────────────────────────────────┐
│              RefreshDatabase の仕組み                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【テスト1回目】                                            │
│                                                             │
│  1. テスト開始前                                            │
│     → DBをマイグレーション（テーブル作成）                 │
│     → DBは空っぽの状態 ✨                                  │
│                                                             │
│  2. テスト実行                                              │
│     → ユーザーを作成                                       │
│     → テスト実行                                           │
│     → ユーザーがDBに存在                                   │
│                                                             │
│  3. テスト終了後                                            │
│     → トランザクションをロールバック                       │
│     → DBが空っぽに戻る ✨                                  │
│                                                             │
│  【テスト2回目】                                            │
│                                                             │
│  1. テスト開始前                                            │
│     → DBは空っぽの状態 ✨（リセット済み）                  │
│                                                             │
│  2. テスト実行                                              │
│     → また新しいユーザーを作成できる！                     │
│     → 重複エラーにならない！                               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**👩‍💻ユーザー：** 「なるほど！毎回リセットされるから、何回テストしても大丈夫なんですね！」

**🐘ガネーシャ：** 「せや！しかも**本番のDBには影響しない**。テスト用のDBだけがリセットされるんや」

---

### 📝 Factory の使い方

**🐘ガネーシャ：** 「実際のコードを見てみよか」

```php
// 基本的な使い方
$user = User::factory()->create();

// これだけで以下のようなユーザーが作られる！
// [
//     'id' => 1,
//     'name' => 'John Doe',        ← ランダムな名前
//     'email' => 'john@example.com', ← ランダムなメール
//     'password' => '暗号化されたパスワード',
//     ...
// ]
```

**👩‍💻ユーザー：** 「1行でユーザーが作れる...！」

**🐘ガネーシャ：** 「しかもな、特定の値を指定することもできるんや」

```php
// 名前とメールを指定して作成

    'name' => '山田太郎',
    'email' => 'yamada@example.com',
]);

// 指定した値 + 残りはランダム
// [
//     'id' => 1,
//     'name' => '山田太郎',           ← 指定した値
//     'email' => 'yamada@example.com', ← 指定した値
//     'password' => '暗号化されたパスワード', ← デフォルト
//     ...
// ]
```

**👩‍💻ユーザー：** 「テストで確認したい値だけ指定すればいいんですね！」

### 📊 手動作成 vs Factory

**🐘ガネーシャ：** 「比較してみよか」

```
┌─────────────────────────────────────────────────────────────┐
│              手動作成 vs Factory                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【手動作成】6行                                            │
│                                                             │
│  $user = new User();                                        │
│  $user->name = 'テスト太郎';                                │
│  $user->email = 'test@example.com';                         │
│  $user->password = bcrypt('password');                      │
│  $user->email_verified_at = now();                          │
│  $user->save();                                             │
│                                                             │
```

## 📖 第4章：正しいテストを書いてみよう

### 🎭 Factory + RefreshDatabase を使ったテスト

**🐘ガネーシャ：** 「ほな、さっきの失敗したテストを正しく書き直してみよか」

```php
<?php
// tests/Feature/Api/UserTest.php（正しい例）

namespace Tests\Feature\Api;

use App\Models\User;
use Illuminate\Foundation\Testing\RefreshDatabase;
use Tests\TestCase;

class UserTest extends TestCase
{
    use RefreshDatabase;  // ← これでDBが毎回リセット！

    /**
     * 認証済みユーザーの情報を取得できる
     */
    public function test_can_get_authenticated_user(): void
    {
        // ============================================
        // 1. Arrange（準備）
        // ============================================
        // Factory でユーザーを作成（1行！）
        $user = User::factory()->create([
            'name' => '山田太郎',
            'email' => 'yamada@example.com',
        ]);

        // ============================================
        // 2. Act（実行）
        // ============================================
        // actingAs でログイン状態にしてリクエスト
        $response = $this->actingAs($user)
            ->getJson('/api/user');

        // ============================================
        // 3. Assert（検証）
        // ============================================
        $response->assertStatus(200);
        $response->assertJson([
            'name' => '山田太郎',
            'email' => 'yamada@example.com',
        ]);
    }
}
```

**👩‍💻ユーザー：** 「おお、スッキリ！」
