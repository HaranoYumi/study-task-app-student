## 📖 第2章：テストの優先度の考え方

### 🎭 優先度の高いテスト

**🐘ガネーシャ：** 「テストの優先度を考える時、こう考えるとええで」

```
┌─────────────────────────────────────────────────────────────┐
│               テストの優先度ピラミッド                       │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│                        ▲                                    │
│                       /＼                                   │
│                      /  ＼                                  │
│                     / 低  ＼  ← 細かいUI、見た目           │
│                    /────────＼                              │
│                   /    中     ＼ ← バリデーション          │
│                  /──────────────＼                          │
│                 /       高        ＼ ← ビジネスロジック    │
│                /────────────────────＼                      │
│               /        最高          ＼ ← 認証・認可        │
│              ──────────────────────────                    │
│                                                             │
│  【最高】認証・認可（セキュリティ）                         │
│    → 他人のデータが見えたら大問題                          │
│    → Lesson 7-5 の 401, 403, 404(アクセス権) テスト        │
│                                                             │
│  【高】ビジネスロジック（業務ルール）                       │
│    → お金や重要なステータスに関わる処理                    │
│    → Lesson 7-5 の 409 テスト                              │
│                                                             │
│  【中】バリデーション（入力チェック）                       │
│    → 不正なデータが入るのを防ぐ                            │
│    → Lesson 7-5 の 422 テスト                              │
│                                                             │
│  【低】細かいUI、見た目                                     │
│    → 後回しでもOK                                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**👩‍💻ユーザー：** 「Lesson 7-5 で学んだエラーコードが、優先度と対応してるんですね！」

**🐘ガネーシャ：** 「せや！401, 403, 404 は**セキュリティ**、409 は**ビジネスルール**、422 は**バリデーション**やったな。これがそのまま優先度になるんや」

    $user = User::factory()->create();
    
    // 作成
    $response = $this->actingAs($user)->postJson('/api/projects', ['name' => 'テスト']);
    $response->assertStatus(201);
    
    // 取得
    $response = $this->actingAs($user)->getJson('/api/projects');
    $response->assertStatus(200);

}
